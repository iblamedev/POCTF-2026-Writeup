## Overview

Someone has gone to extraordinary lengths to make a simple message difficult to read.

You've recovered a fragment of text written in a language you don't recognize, wrapped inside another language you don't recognize, wrapped inside another...

Four layers. Four alphabets. One message.

Start peeling.

## Solve

Multi-language polyglot code executing different logic in Python, C, and Ruby.

Constructed execution chain where comments and string literals in one language acted as valid syntax in another, extracting all language fragments.
