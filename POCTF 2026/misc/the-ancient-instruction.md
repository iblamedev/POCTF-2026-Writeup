## Overview

Recovered debris. Eight instructions.

That's all we've got.

Whatever produced this artifact apparently assumed you'd know what to do with it. No explanation, no helpful documentation, just a strange little program waiting to be understood.

Somewhere in those eight instructions is a message.

## Solve

DEC PDP-11 MACRO-11 assembly program emulation with octal instruction decoding.

Parsed `program-491.txt`, simulated PDP-11 CPU registers (R0-R7) and octal instruction set (`MOV`, `ADD`, `SOB`), extracting output character buffer.
