## Overview

I see something... It's... Some kind of machine. A séance apparatus. Forty-nine candles arranged in a seven-by-seven grid. 

I remeber this, somehow. To invoke, the operator must snuff them all.

## Solve

Custom esoteric virtual machine interpreting pseudo-Latin ceremonial bytecode commands.

Disassembled the invocation bytecode VM, mapped opcodes to stack manipulations (PUSH, ADD, XOR, EMIT), and traced the execution trace to print the flag.
