## Overview

A tiny program has been recovered from somewhere it probably shouldn’t have been.

Run it and you’ll get almost nothing: a single, unremarkable dot.

But the program contains a condition. Under the right circumstances, something else exists.

Find the condition. Satisfy it. See what appears. The source will tell you what to look up — and how to turn what you find into the key.

## Solve

Complex boolean satisfiability problem (SAT) guarding flag output.

Formulated constraints into Z3 theorem prover with 256 boolean variables, solved in 1.2 seconds, and mapped true assignments to ASCII.

### Recovered Token

```text
POCTF{████████████████}
```
